# tests/samples

Inputs and CLI proof for the IGA smoke tests described in
`reports/02-disassembler-environment.md`.  Generated `.krn` binaries and probe
inputs live in `generated/` (regenerated by `run-smoke.sh`); the captured CLI
output lives in `logs/tool-smoke-iga-*.txt`.

## Sources (hand-maintained)

| File | Provenance |
|---|---|
| `iga-jsonv2-example.asm12p72` | Verbatim official example from `intel/intel-graphics-compiler` @ `c36a504a…`, `visa/iga/IGAJSONv2.md` ("Assume XeHPC"). |
| `iga-jsonv2-example-fixed.asm12p72` | Same example with one edit: the final send's `{EOT,A@1}` → `{EOT}`. |
| `igt-gen12-gpgpu-fill.asm12p1` | Intel i-g-t upstream `lib/i915/shaders/gpgpu/gen12_gpgpu_kernel.asm` (MIT), Gen12 / platform `12p1` (Tiger Lake). |
| `gen11-minimal.asm11` | Hand-authored minimal Gen11 (`11`) kernel; **not** an upstream file (see its header). |

## Reproduce

```sh
../../tools/iga/build.sh          # build iga64 (pinned commit, non-destructive)
./run-smoke.sh                    # writes logs/tool-smoke-iga-*.txt and generated/
```

## Observed results (this build, `1.1.0-c36a504`)

- `iga-jsonv2-example.asm12p72` — **fails**: `error: invalid SWSB` at the final
  `send.gtwy … {EOT,A@1}`. The documented example does not assemble here.
- `iga-jsonv2-example-fixed.asm12p72` — assembles (80 B), disassembles, and
  reproduces the documented `-Xprint-json` v2 output.
- `igt-gen12-gpgpu-fill.asm12p1` — assembles (160 B) and round-trips;
  `-Xautocompact` shrinks it to 152 B, `-Xforce-no-compact` keeps 160 B.
- `gen11-minimal.asm11` — assembles (32 B) and round-trips.
- 8 bytes of `0xFF` decode to an `illegal` line with a GED error comment and a
  non-zero exit (add `--output-on-fail` to still print the listing).

The `{EOT,A@1}` rejection and the compaction/unknown behaviour are captured with
exact commands and exit codes in `../../logs/tool-smoke-iga-*.txt`.
